# Third-Party Notices

CodeSprint includes code snippets sourced from third-party open-source projects
for typing practice.

## TheAlgorithms (MIT)

The real code snippets in `data/algorithms-snippets.json` (and the per-language
`data/snippets-*.json` files built from it) are derived from the MIT-licensed
TheAlgorithms repositories:

- TheAlgorithms/Python — https://github.com/TheAlgorithms/Python
- TheAlgorithms/JavaScript — https://github.com/TheAlgorithms/JavaScript
- TheAlgorithms/Java — https://github.com/TheAlgorithms/Java
- TheAlgorithms/C-Plus-Plus — https://github.com/TheAlgorithms/C-Plus-Plus

Each snippet records its upstream path in its `sourceSlug` field. Regenerate with
`bun run sync:algorithms`.
