# Daily CodeSprint Launch Plan

## Positioning

CodeSprint is "Monkeytype for real code": a daily code-typing challenge for typing-practice grinders who already care about WPM, streaks, and shareable scores.

Do not lead with interview prep, AI drills, spaced repetition, or "become a better engineer." Those are product depth, not the first hook. The hook is the sport loop:

- same real-code snippet for everyone
- code WPM instead of prose WPM
- streak pressure
- compact result sharing
- low-friction daily return

## First Launch Channel

Pick one channel for the first 48-hour test:

1. Monkeytype Discord `#show-and-tell`
2. `r/monkeytype`

Do not cross-post on day one. The goal is not reach; it is signal quality.

## Success Metric

Primary question: does at least one stranger come back the next day without a nudge?

Track:

- day-one visits from the chosen channel
- completed daily runs
- copied/shared result blocks
- day-two returning visitors
- replies that include an actual score, not just "cool project"

## Follow-Up If There Is Signal

If strangers post scores or return on day two, build the next sport-loop feature:

1. race links against the same snippet
2. personal-best ghost cursor
3. timed and zen modes
4. daily or weekly public board

If nobody returns, fix the offer before building: snippet length, score trust, first-run friction, or the launch copy.
